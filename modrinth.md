Компат Create и Hamsters для Minecraft 1.20.1. Вал стыкуется со ступицей колеса, хомяк его крутит. Один jar ставится на Forge 47 и на NeoForge 20.1. Fabric-jar в этом проекте нет. Java 17.

## Forge и NeoForge 20.1

Обязательно: `hamsterscreatecompat-forge-1.20.1-1.0.0.jar`, Kotlin for Forge 4.12.0, Create 6.0.8, Hamsters `1.20.1-1.0.3` (Forge), GeckoLib 4.4.9.

## Fabric

Сборки нет. У Create 6.0.8 на 1.20.1 нет официального Fabric-jar.

Create and Hamsters compatibility for Minecraft 1.20.1. A shaft connects to the wheel hub, and the hamster turns it. One jar runs on Forge 47 and NeoForge 20.1. This project has no Fabric jar. Java 17.

## Forge and NeoForge 20.1

Required: `hamsterscreatecompat-forge-1.20.1-1.0.0.jar`, Kotlin for Forge 4.12.0, Create 6.0.8, Hamsters `1.20.1-1.0.3` (Forge), and GeckoLib 4.4.9.

## Fabric

No build. Create 6.0.8 for 1.20.1 has no official Fabric jar.
